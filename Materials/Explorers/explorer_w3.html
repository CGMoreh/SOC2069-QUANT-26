Modelling continuous outcomes

Interactive explorer

The three tools below use the Spirit Level data from the lecture and Worksheet 3: income inequality (the ratio between the incomes of the richest and the poorest fifths) and the percentage of people who say that most people can be trusted, in 23 rich countries. Each tool recalculates as you move its sliders.

navy = "#1F394D"
gold = "#B88C00"
dkgold = "#7A5C00"
grey = "#55606B"
fmt = (v, d = 2) => v.toFixed(d).replace("-", "−")
sl = [{"country": "Australia", "x": 7.0, "y": 39.9}, {"country": "Austria", "x": 4.825, "y": 33.9}, {"country": "Belgium", "x": 4.6, "y": 30.7}, {"country": "Canada", "x": 5.625, "y": 38.8}, {"country": "Denmark", "x": 4.3, "y": 66.5}, {"country": "Finland", "x": 3.725, "y": 58.0}, {"country": "France", "x": 5.6, "y": 22.2}, {"country": "Germany", "x": 5.2, "y": 34.8}, {"country": "Greece", "x": 6.2, "y": 23.7}, {"country": "Ireland", "x": 6.05, "y": 35.2}, {"country": "Israel", "x": 6.775, "y": 23.5}, {"country": "Italy", "x": 6.65, "y": 32.6}, {"country": "Japan", "x": 3.4, "y": 43.1}, {"country": "Netherlands", "x": 5.3, "y": 59.8}, {"country": "New Zealand", "x": 6.8, "y": 49.1}, {"country": "Norway", "x": 3.85, "y": 65.3}, {"country": "Portugal", "x": 8.0, "y": 10.0}, {"country": "Singapore", "x": 9.7, "y": 16.9}, {"country": "Spain", "x": 5.55, "y": 36.2}, {"country": "Sweden", "x": 3.95, "y": 66.3}, {"country": "Switzerland", "x": 5.725, "y": 41.0}, {"country": "UK", "x": 7.175, "y": 29.8}, {"country": "USA", "x": 8.55, "y": 35.8}]
ols = pts => {
  const mx = d3.mean(pts, d => d.x), my = d3.mean(pts, d => d.y);
  const b = d3.sum(pts, d => (d.x - mx) * (d.y - my)) / d3.sum(pts, d => (d.x - mx) ** 2);
  const a = my - b * mx;
  const sst = d3.sum(pts, d => (d.y - my) ** 2);
  const ssr = d3.sum(pts, d => (d.y - a - b * d.x) ** 2);
  return {a, b, r2: 1 - ssr / sst, ssr, sst};
}
fit = ols(sl)
lineEq = f => `${fmt(f.a)} ${f.b < 0 ? "−" : "+"} ${Math.abs(f.b).toFixed(3)} × inequality`

Fitting the line by hand

The least-squares line is the line with the smallest sum of squared residuals: the grey vertical gaps between each country and the line, squared and added up. Move the intercept and the slope to make that sum as small as you can, then tick the box to compare your line with the one that JASP fits.

viewof a = Inputs.range([0, 120], {value: 60, step: 0.5, label: "Intercept"})
viewof b = Inputs.range([-15, 5], {value: -3, step: 0.05, label: "Slope"})
viewof showLS = Inputs.toggle({label: "Show the least-squares line", value: false})
mine = {
  const ssr = d3.sum(sl, d => (d.y - a - b * d.x) ** 2);
  return {ssr, r2: 1 - ssr / fit.sst};
}
Plot.plot({
  width: Math.min(width, 760), height: 380, marginLeft: 50,
  x: {domain: [0, 10], label: "Income inequality (richest fifth ÷ poorest fifth)"},
  y: {domain: [0, 100], label: "% who say most people can be trusted", grid: true},
  style: {fontSize: "12px"},
  marks: [
    Plot.link(sl, {x1: "x", y1: "y", x2: "x", y2: d => a + b * d.x, stroke: "#9AA3AB", strokeWidth: 1.5, clip: true}),
    Plot.line([[0, a], [10, a + 10 * b]], {stroke: gold, strokeWidth: 3, clip: true}),
    showLS ? Plot.line([[0, fit.a], [10, fit.a + 10 * fit.b]], {stroke: navy, strokeWidth: 2, strokeDasharray: "6,4"}) : null,
    Plot.dot(sl, {x: "x", y: "y", r: 5, fill: navy, stroke: "white", title: d => `${d.country}: ${d.y}%`}),
    Plot.dot([[0, a]], {x: d => d[0], y: d => d[1], r: 6, fill: gold, stroke: "white"})
  ]
})
md`- **Your line**: ${lineEq({a, b})}; sum of squared residuals ${Math.round(mine.ssr).toLocaleString("en-GB")}; ${mine.r2 >= 0 ? `it accounts for ${(100 * mine.r2).toFixed(0)}% of the variation in trust` : "it predicts worse than giving every country the average trust"}
- **Least squares**, as fitted by JASP: ${lineEq(fit)}; sum of squared residuals ${Math.round(fit.ssr).toLocaleString("en-GB")}; R² = ${fit.r2.toFixed(2)}`

One more country

Add a hypothetical country and move it around. A country close to the line changes little, but a country far from the others, above all at an extreme of inequality, can pull the line towards itself, as in the ‘one influential point’ panel of Anscombe’s quartet. The grey dashed line is the fit without the extra country.

viewof addOn = Inputs.toggle({label: "Add the extra country", value: true})
viewof nx = Inputs.range([1, 15], {value: 12, step: 0.1, label: "Its inequality"})
viewof ny = Inputs.range([0, 100], {value: 70, step: 1, label: "Its trust"})
fit2 = addOn ? ols([...sl, {x: nx, y: ny}]) : fit
Plot.plot({
  width: Math.min(width, 760), height: 380, marginLeft: 50,
  x: {domain: [0, 15], label: "Income inequality (richest fifth ÷ poorest fifth)"},
  y: {domain: [0, 100], label: "% who say most people can be trusted", grid: true},
  style: {fontSize: "12px"},
  marks: [
    Plot.line([[0, fit.a], [15, fit.a + 15 * fit.b]], {stroke: "#9AA3AB", strokeWidth: 2, strokeDasharray: "6,4", clip: true}),
    Plot.line([[0, fit2.a], [15, fit2.a + 15 * fit2.b]], {stroke: gold, strokeWidth: 3, clip: true}),
    Plot.dot(sl, {x: "x", y: "y", r: 5, fill: navy, stroke: "white", title: d => d.country}),
    addOn ? Plot.dot([{x: nx, y: ny}], {x: "x", y: "y", r: 8, fill: gold, stroke: navy, strokeWidth: 2}) : null
  ]
})
html`<table class="table table-sm" style="max-width: 620px;">
<thead><tr><th></th><th style="text-align: right;">Intercept</th><th style="text-align: right;">Slope</th><th style="text-align: right;">R²</th></tr></thead>
<tbody>
<tr><td>23 countries</td><td style="text-align: right;">${fmt(fit.a)}</td><td style="text-align: right;">${fmt(fit.b, 3)}</td><td style="text-align: right;">${fit.r2.toFixed(2)}</td></tr>
<tr><td>With the extra country</td><td style="text-align: right;">${addOn ? fmt(fit2.a) : "–"}</td><td style="text-align: right;">${addOn ? fmt(fit2.b, 3) : "–"}</td><td style="text-align: right;">${addOn ? fit2.r2.toFixed(2) : "–"}</td></tr>
</tbody></table>`

Predictions and residuals

Choose a country to compare the trust that the line predicts for its level of inequality with the trust actually observed there. The residual is the observed value minus the predicted one: positive for countries above the line, negative for those below it.

viewof country = Inputs.select(sl.map(d => d.country), {value: "Portugal", label: "Country"})
sel = sl.find(d => d.country === country)
pred = fit.a + fit.b * sel.x
html`<table class="table table-sm" style="max-width: 620px;">
<thead><tr><th>Step</th><th>Calculation</th><th style="text-align: right;">Result</th></tr></thead>
<tbody>
<tr><td>Predicted trust</td><td>${fmt(fit.a)} − ${Math.abs(fit.b).toFixed(3)} × ${sel.x}</td><td style="text-align: right;">${pred.toFixed(1)}%</td></tr>
<tr><td>Observed trust</td><td>${sel.country}</td><td style="text-align: right;">${sel.y.toFixed(1)}%</td></tr>
<tr><td>Residual</td><td>${sel.y.toFixed(1)} − ${pred.toFixed(1)}</td><td style="text-align: right;"><strong>${fmt(sel.y - pred, 1)} points</strong></td></tr>
</tbody></table>`
Plot.plot({
  width: Math.min(width, 760), height: 340, marginLeft: 50,
  x: {domain: [0, 10], label: "Income inequality (richest fifth ÷ poorest fifth)"},
  y: {domain: [0, 100], label: "% who say most people can be trusted", grid: true},
  style: {fontSize: "12px"},
  marks: [
    Plot.line([[0, fit.a], [10, fit.a + 10 * fit.b]], {stroke: gold, strokeWidth: 2.5}),
    Plot.dot(sl, {x: "x", y: "y", r: 4, fill: "#9AA3AB"}),
    Plot.link([sel], {x1: "x", y1: "y", x2: "x", y2: () => pred, stroke: dkgold, strokeWidth: 3}),
    Plot.dot([sel], {x: "x", y: "y", r: 8, fill: navy, stroke: "white"}),
    Plot.text([sel], {x: "x", y: "y", text: "country", dx: 12, textAnchor: "start", fill: navy, fontWeight: "bold", fontSize: 13})
  ]
})
