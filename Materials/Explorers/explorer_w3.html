Modelling continuous outcomes

Interactive explorer

The four tools below use the Spirit Level data from the lecture and Worksheet 3: income inequality (the ratio between the incomes of the richest and the poorest fifths) and the percentage of people who say that most people can be trusted, in 23 rich countries, together with homicide rates in the last tool. Each tool recalculates as you change its settings.

navy = "#1F394D"
gold = "#B88C00"
dkgold = "#7A5C00"
grey = "#55606B"

// fmt(v, d): the number v as text with d decimals (2 unless given), with the hyphen that
// toFixed() puts before a negative number replaced by a true minus sign (U+2212), so that
// numbers look the same as on the slides. Only the first hyphen is replaced, which is all
// that a single number can contain.
fmt = (v, d = 2) => v.toFixed(d).replace("-", "−")

// sl: the 23 countries of the Spirit Level data (pickett2009.csv). x is income inequality,
// the ratio between the incomes of the richest and the poorest fifths, and y is the
// percentage who say that most people can be trusted.
sl = [{"country": "Australia", "x": 7.0, "y": 39.9}, {"country": "Austria", "x": 4.825, "y": 33.9}, {"country": "Belgium", "x": 4.6, "y": 30.7}, {"country": "Canada", "x": 5.625, "y": 38.8}, {"country": "Denmark", "x": 4.3, "y": 66.5}, {"country": "Finland", "x": 3.725, "y": 58.0}, {"country": "France", "x": 5.6, "y": 22.2}, {"country": "Germany", "x": 5.2, "y": 34.8}, {"country": "Greece", "x": 6.2, "y": 23.7}, {"country": "Ireland", "x": 6.05, "y": 35.2}, {"country": "Israel", "x": 6.775, "y": 23.5}, {"country": "Italy", "x": 6.65, "y": 32.6}, {"country": "Japan", "x": 3.4, "y": 43.1}, {"country": "Netherlands", "x": 5.3, "y": 59.8}, {"country": "New Zealand", "x": 6.8, "y": 49.1}, {"country": "Norway", "x": 3.85, "y": 65.3}, {"country": "Portugal", "x": 8.0, "y": 10.0}, {"country": "Singapore", "x": 9.7, "y": 16.9}, {"country": "Spain", "x": 5.55, "y": 36.2}, {"country": "Sweden", "x": 3.95, "y": 66.3}, {"country": "Switzerland", "x": 5.725, "y": 41.0}, {"country": "UK", "x": 7.175, "y": 29.8}, {"country": "USA", "x": 8.55, "y": 35.8}]

// ss: the simple-statistics package, version 7.12.1, which require() fetches from the
// jsDelivr CDN. It supplies every least-squares fit on this page: linearRegression() takes
// [x, y] pairs and returns {m, b}, the slope and the intercept, and linearRegressionLine()
// turns that result into a function that predicts y from x.
ss = require("simple-statistics@7.12.1")
pairs = sl.map(d => [d.x, d.y])
lsLine = ss.linearRegression(pairs)

// fit: what the tools report about the least-squares line of trust on inequality, namely
// the intercept a, the slope b, R-squared (r2), the sum of squared residuals (ssr, the
// quantity that least squares makes as small as possible) and the total sum of squares
// around the mean of trust (sst, which is the sum of squared residuals of a flat line at
// the mean). The first tool compares a student's line with it, the second uses it as the
// fit without the extra country, the third predicts from it and the fourth quotes its slope.
fit = ({a: lsLine.b, b: lsLine.m, r2: ss.rSquared(pairs, ss.linearRegressionLine(lsLine)), ssr: d3.sum(sl, d => (d.y - lsLine.b - lsLine.m * d.x) ** 2), sst: ss.sumNthPowerDeviations(sl.map(d => d.y), 2)})

// lineEq(f): the equation of a fitted line as text, "a - b × inequality", with the
// intercept to two decimals and the slope to three, as JASP prints them.
lineEq = f => `${fmt(f.a)} ${f.b < 0 ? "−" : "+"} ${Math.abs(f.b).toFixed(3)} × inequality`

Fitting the line by hand

The least-squares line is the line with the smallest sum of squared residuals: the grey vertical gaps between each country and the line, squared and added up. Move the intercept and the slope to make that sum as small as you can, then tick the box to compare your line with the one that JASP fits.

viewof a = Inputs.range([0, 120], {value: 60, step: 0.5, label: "Intercept"})
viewof b = Inputs.range([-15, 5], {value: -3, step: 0.05, label: "Slope"})
viewof showLS = Inputs.toggle({label: "Show the least-squares line", value: false})
// mine: the sum of squared residuals of the line set with the two sliders, and its
// R-squared (1 - ssr / sst), which falls below 0 when that line predicts worse than the
// mean of trust.
mine = {
  const ssr = d3.sum(sl, d => (d.y - a - b * d.x) ** 2);
  return {ssr, r2: 1 - ssr / fit.sst};
}
Plot.plot({
  width: Math.min(width, 760), height: 380, marginLeft: 50,

  y: {domain: [0, 100], label: "% who say most people can be trusted", grid: true},
  style: {fontSize: "12px"},
  marks: [
    Plot.link(sl, {x1: "x", y1: "y", x2: "x", y2: d => a + b * d.x, stroke: "#9AA3AB", strokeWidth: 1.5, clip: true}),
    Plot.line([[0, a], [10, a + 10 * b]], {stroke: gold, strokeWidth: 3, clip: true}),
    showLS ? Plot.line([[0, fit.a], [10, fit.a + 10 * fit.b]], {stroke: navy, strokeWidth: 2, strokeDasharray: "6,4"}) : null,
    Plot.dot(sl, {x: "x", y: "y", r: 5, fill: navy, stroke: "white", title: d => `${d.country}: ${d.y}%`}),
    Plot.dot([[0, a]], {x: d => d[0], y: d => d[1], r: 6, fill: gold, stroke: "white"})
  ]
})
md`- **Your line**: ${lineEq({a, b})}; sum of squared residuals ${Math.round(mine.ssr).toLocaleString("en-GB")}; ${mine.r2 >= 0 ? `it accounts for ${(100 * mine.r2).toFixed(0)}% of the variation in trust` : "it predicts worse than giving every country the average trust"}
- **Least squares**, as fitted by JASP: ${lineEq(fit)}; sum of squared residuals ${Math.round(fit.ssr).toLocaleString("en-GB")}; R² = ${fit.r2.toFixed(2)}`

One more country

Add a hypothetical country and move it around. A country close to the line changes little, but a country far from the others, above all at an extreme of inequality, can pull the line towards itself, as in the ‘one influential point’ panel of Anscombe’s quartet. The grey dashed line is the fit without the extra country.

viewof addOn = Inputs.toggle({label: "Add the extra country", value: true})
viewof nx = Inputs.range([1, 15], {value: 12, step: 0.1, label: "Its inequality"})
viewof ny = Inputs.range([0, 100], {value: 70, step: 1, label: "Its trust"})
pairs2 = [...pairs, [nx, ny]]
line2 = ss.linearRegression(pairs2)
fit2 = addOn ? ({a: line2.b, b: line2.m, r2: ss.rSquared(pairs2, ss.linearRegressionLine(line2))}) : fit

Adjusting for homicide rates

In the lecture, adding homicide rates to the model changed the coefficient for inequality from −6.54 to −7.15. As Allison (1998:109–12) shows, the same coefficient can be rebuilt from three simple regressions on all 23 countries, which makes visible what ‘adjusting for’ a variable does. You never need to do this in practice, since JASP gives the same coefficient in one go, but the steps show where it comes from.

Choose a country to follow it through the three steps. The USA is a good place to start, because it is the second most unequal country in the data and also has by far the highest homicide rate. In step 2 its homicide rate predicts almost exactly the inequality that it has, so in step 3 the USA sits close to zero on the inequality axis.

hom = ({"Australia": 16.9, "Austria": 11.6, "Belgium": 13.0, "Canada": 17.3, "Denmark": 12.7, "Finland": 28.2, "France": 21.5, "Germany": 13.7, "Greece": 13.9, "Ireland": 8.6, "Israel": 25.4, "Italy": 19.9, "Japan": 5.2, "Netherlands": 14.5, "New Zealand": 12.3, "Norway": 9.7, "Portugal": 34.6, "Singapore": 15.5, "Spain": 8.1, "Sweden": 18.7, "Switzerland": 12.7, "UK": 15.0, "USA": 64.0})
slh = sl.map(d => ({...d, h: hom[d.country]}))

// The three regressions of Allison (1998, pp. 109-112). step1 regresses trust on homicide
// rates and step2 regresses inequality on homicide rates. resid keeps the residuals of
// every country from both, ry for trust and rx for inequality, and step3 regresses ry on
// rx. The slope of step3 equals the inequality coefficient of the two-predictor model in
// JASP (-7.147), and its intercept is 0 because residuals always average zero.
step1 = ss.linearRegression(slh.map(d => [d.h, d.y]))
step2 = ss.linearRegression(slh.map(d => [d.h, d.x]))
resid = slh.map(d => ({...d, ry: d.y - (step1.b + step1.m * d.h), rx: d.x - (step2.b + step2.m * d.h)}))
step3 = ss.linearRegression(resid.map(d => [d.rx, d.ry]))

// rh: the correlations of homicide rates with the trust residuals and with the inequality
// residuals. Both are 0 up to rounding error, because residuals from least squares are
// always uncorrelated with the predictor of their own regression; this is the sense in
// which the residuals are "purged" of homicide rates (Allison 1998, p. 111).
rh = [ss.sampleCorrelation(resid.map(d => d.h), resid.map(d => d.ry)), ss.sampleCorrelation(resid.map(d => d.h), resid.map(d => d.rx))]
viewof follow = Inputs.select(slh.map(d => d.country), {value: "USA", label: "Country"})
// fsel: the chosen country, with its two residuals.
fsel = resid.find(d => d.country === follow)

Regress the trust residuals from step 1 on the inequality residuals from step 2. The slope of this line is the coefficient for inequality in the multiple regression. The line passes through zero on both axes, because residuals always average zero.

Adjusting for homicide rates therefore means relating the part of inequality that homicide rates do not predict to the part of trust that homicide rates do not predict. No country is dropped, and no two countries need to have the same homicide rate, because multiple regression can adjust for a variable even when no two cases share a value of it (Allison 1998:19). This comes with two conditions: the relationships have to be roughly straight lines (Allison 1998:20), and only the variables that are in the model are adjusted for.
