Uncertainty and Inference

Interactive explorer

The three tools below simulate the ideas from the lecture. The first two draw random samples from a population in which 45.4% trust most people, the share found in the British Social Attitudes survey 2010; the third shuffles the Spirit Level data. Every click of a button draws new random numbers, so your results will differ a little from anyone else’s.

navy = "#1F394D"
gold = "#B88C00"
blue = "#3F739B"
dkgold = "#7A5C00"
light = "#CCDDEA"

// fmt(v, d): the number v as text with d decimals (2 unless given), with the hyphen that
// toFixed() puts before a negative number replaced by a true minus sign (U+2212), so that
// numbers look the same as on the slides. Only the first hyphen is replaced, which is all
// that a single number can contain.
fmt = (v, d = 2) => v.toFixed(d).replace("-", "−")

// pct(v, d): the proportion v as a percentage with d decimals (1 unless given), so that
// 0.4537 becomes "45.4%".
pct = (v, d = 1) => `${(100 * v).toFixed(d)}%`

// randBinom(n, p): the number of people who trust in one random sample of n people from a
// population in which the share p trusts. It asks the n people one by one: each uniform
// random number below p counts as one person who trusts, which is exactly what the first
// two tools describe. That is fast enough here, at most two million draws per click
// (1,000 samples of up to 2,000 people); d3.randomBinomial(n, p) would give the same
// distribution without the loop.
randBinom = (n, p) => {
  let k = 0;
  for (let i = 0; i < n; i++) if (Math.random() < p) k++;
  return k;
}

// sl: the 23 countries of the Spirit Level data (pickett2009.csv), with x for income
// inequality and y for the percentage who say that most people can be trusted, as in the
// Week 3 explorer.
sl = [{"x": 7.0, "y": 39.9}, {"x": 4.825, "y": 33.9}, {"x": 4.6, "y": 30.7}, {"x": 5.625, "y": 38.8}, {"x": 4.3, "y": 66.5}, {"x": 3.725, "y": 58.0}, {"x": 5.6, "y": 22.2}, {"x": 5.2, "y": 34.8}, {"x": 6.2, "y": 23.7}, {"x": 6.05, "y": 35.2}, {"x": 6.775, "y": 23.5}, {"x": 6.65, "y": 32.6}, {"x": 3.4, "y": 43.1}, {"x": 5.3, "y": 59.8}, {"x": 6.8, "y": 49.1}, {"x": 3.85, "y": 65.3}, {"x": 8.0, "y": 10.0}, {"x": 9.7, "y": 16.9}, {"x": 5.55, "y": 36.2}, {"x": 3.95, "y": 66.3}, {"x": 5.725, "y": 41.0}, {"x": 7.175, "y": 29.8}, {"x": 8.55, "y": 35.8}]

// binEdges(n): histogram bin edges for the shares found in samples of n people. A sample
// share can only be 0, 1/n, 2/n, ..., 1, so every edge lies halfway between two possible
// shares and every bin holds the same number m of them: m = 1 up to n = 200, and above
// that the smallest whole number that keeps bins at least half a percentage point wide.
// Bins holding unequal numbers of possible shares (one and two alternately at n = 300,
// for instance) would give the histogram a sawtooth that says nothing about sampling.
binEdges = n => {
  const m = Math.max(1, Math.ceil(0.005 * n));
  return d3.range(-0.5 / n, 1 + m / n, m / n);
}

// slope(xs, ys): the least-squares slope of ys on xs, that is, the sum of the products of
// the deviations from the two means divided by the sum of squared deviations of xs.
// "Shuffling the countries" calls it 1,001 times per click (the real data and 1,000
// shuffles), which is why it computes the slope alone and nothing else.
slope = (xs, ys) => {
  const mx = d3.mean(xs), my = d3.mean(ys);
  return d3.sum(xs, (x, i) => (x - mx) * (ys[i] - my)) / d3.sum(xs, x => (x - mx) ** 2);
}

Samples vary

Each click draws 1,000 random samples of the chosen size and records the share who trust in each one. The histogram of those 1,000 shares is the sampling distribution: centred on the true share, and narrower for bigger samples. Its spread is the standard error.

viewof p5 = Inputs.range([0.05, 0.95], {value: 0.454, step: 0.001, label: "True share"})
viewof n5 = Inputs.range([20, 2000], {value: 100, step: 10, label: "Sample size"})
viewof draw = Inputs.button("Draw 1,000 new samples")
// sims: the share who trust in each of 1,000 samples of n5 people. Naming the button
// (draw) inside the cell makes it run afresh on every click.
sims = {
  draw;
  return d3.range(1000).map(() => randBinom(n5, p5) / n5);
}
Plot.plot({
  width: Math.min(width, 760), height: 300, marginLeft: 50,
  x: {domain: [Math.max(0, p5 - 0.25), Math.min(1, p5 + 0.25)], label: "Share who trust in each sample", tickFormat: "%"},
  y: {label: "Samples", grid: true},
  style: {fontSize: "12px"},
  marks: [
    Plot.rectY(sims, Plot.binX({y: "count"}, {x: d => d, thresholds: binEdges(n5), fill: light, stroke: "white"})),
    Plot.ruleX([p5], {stroke: gold, strokeWidth: 2.5}),
    Plot.ruleY([0])
  ]
})
md`- **Spread of the 1,000 estimates** (their standard deviation): ${(100 * d3.deviation(sims)).toFixed(2)} percentage points
- **Standard error from the formula** √(p(1 − p) ÷ n): ${(100 * Math.sqrt(p5 * (1 - p5) / n5)).toFixed(2)} percentage points
- **The middle 95% of estimates** ran from ${pct(d3.quantile(sims, 0.025))} to ${pct(d3.quantile(sims, 0.975))}`

Fifty intervals

Each click draws 50 samples and builds a confidence interval from each, as you would from a single survey. Intervals that miss the true share of 45.4% are drawn in gold. Over many draws, about 95% of 95% intervals catch the true value; any one interval either does or does not, and with real data we cannot tell which.

viewof nci = Inputs.range([20, 2000], {value: 200, step: 10, label: "Sample size"})
viewof level = Inputs.radio(["90%", "95%", "99%"], {value: "95%", label: "Confidence level"})
viewof redraw = Inputs.button("Draw 50 new samples")
cis = {
  redraw;
  const z = {"90%": 1.645, "95%": 1.96, "99%": 2.576}[level];
  return d3.range(50).map(i => {
    const est = randBinom(nci, 0.454) / nci;
    const se = Math.sqrt(est * (1 - est) / nci);
    return {i: i + 1, est, lo: est - z * se, hi: est + z * se, covers: est - z * se <= 0.454 && est + z * se >= 0.454};
  });
}
covered = cis.filter(d => d.covers).length
Plot.plot({
  width: Math.min(width, 760), height: 460, marginLeft: 40,
  x: {domain: [0.2, 0.7], label: "Share who trust", tickFormat: "%"},
  y: {domain: [0.5, 50.5], label: "Sample", ticks: [1, 10, 20, 30, 40, 50]},
  style: {fontSize: "12px"},
  marks: [
    Plot.ruleX([0.454], {stroke: navy, strokeDasharray: "5,4"}),
    Plot.link(cis, {x1: "lo", x2: "hi", y1: "i", y2: "i", stroke: d => d.covers ? navy : gold, strokeWidth: 2, clip: true}),
    Plot.dot(cis, {x: "est", y: "i", r: 2.5, fill: d => d.covers ? navy : gold})
  ]
})
md`**${covered} of 50** intervals contain the true share of 45.4%. With ${level} confidence we would expect about ${({"90%": 45, "95%": 47.5, "99%": 49.5})[level]} on average.`

Shuffling the countries

Is a slope of −6.54 surprising if inequality had nothing to do with trust? Shuffling the trust values across the 23 countries breaks any real link, so each shuffle shows a slope produced by chance alone. Each click runs 1,000 shuffles.

viewof shuffle = Inputs.button("Shuffle 1,000 times")
xs = sl.map(d => d.x)
ys = sl.map(d => d.y)
observed = slope(xs, ys)
perm = {
  shuffle;
  return d3.range(1000).map(() => slope(xs, d3.shuffle(ys.slice())));
}
extreme = perm.filter(b => Math.abs(b) >= Math.abs(observed)).length
Plot.plot({
  width: Math.min(width, 760), height: 300, marginLeft: 50,
  x: {domain: [-10, 10], label: "Slope after shuffling trust across countries"},
  y: {label: "Shuffles", grid: true},
  style: {fontSize: "12px"},
  marks: [
    Plot.rectY(perm, Plot.binX({y: "count"}, {x: d => d, thresholds: d3.range(-10, 10.001, 0.5), fill: light, stroke: "white"})),
    Plot.ruleX([observed], {stroke: gold, strokeWidth: 3}),
    Plot.text([observed], {x: d => d, frameAnchor: "top", dy: 8, dx: 6, textAnchor: "start", text: d => `real slope ${fmt(d)}`, fill: dkgold, fontWeight: "bold"}),
    Plot.ruleY([0])
  ]
})
md`**${extreme} of 1,000** shuffles gave a slope at least as far from 0 as the real one, in either direction: an estimated p-value of ${extreme === 0 ? "less than 0.001" : (extreme / 1000).toFixed(3)}. The t-test for the slope in JASP gives p = 0.0005.`
