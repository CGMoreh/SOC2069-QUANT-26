Comparisons and Associations

Interactive explorer

The three tools below accompany the lecture slides. Each one recalculates as you move its sliders or change its numbers.

navy = "#1F394D"
gold = "#B88C00"
blue = "#3F739B"
dkgold = "#7A5C00"
light = "#CCDDEA"

// fmt(v, d): the number v as text with d decimals (2 unless given), with the hyphen that
// toFixed() puts before a negative number replaced by a true minus sign (U+2212), so that
// numbers look the same as on the slides. Only the first hyphen is replaced, which is all
// that a single number can contain.
fmt = (v, d = 2) => v.toFixed(d).replace("-", "−")

// dnorm(x, m, s): the height of the normal curve with mean m and standard deviation s at
// the point x, written out from the formula of the normal density (the name follows the
// dnorm function in R). "Same gap, different overlap" evaluates it along a grid of scores
// to draw the two groups; only the shape of the curves matters there, which is why that
// plot hides its y axis.
dnorm = (x, m, s) => Math.exp(-0.5 * ((x - m) / s) ** 2) / (s * Math.sqrt(2 * Math.PI))

// pnorm(z): the share of a standard normal distribution that lies below z, that is, its
// cumulative distribution function (the name follows the pnorm function in R). It uses
// the five-term polynomial approximation of Abramowitz and Stegun (1964, formula 26.2.17):
// t rescales |z|, d is the height of the normal curve at z, and the nested polynomial in
// t, multiplied by d, gives the upper tail beyond |z|. The last line turns that tail into
// the share below z for either sign of z. With the rounded constants used here the result
// differs from the exact value by at most 2.1e-7 between z = -6 and z = 6, far below
// anything the page prints. Used for the overlap in "Same gap, different overlap".
pnorm = z => {
  const t = 1 / (1 + 0.2316419 * Math.abs(z));
  const d = 0.3989423 * Math.exp(-z * z / 2);
  const p = d * t * (0.3193815 + t * (-0.3565638 + t * (1.781478 + t * (-1.821256 + t * 1.330274))));
  return z > 0 ? 1 - p : p;
}

// pearson(pts): Pearson's correlation r for an array of points {x, y}: the sum of the
// products of the deviations from the two means, divided by the square root of the
// product of the two sums of squared deviations. It returns the same r as JASP. Used
// under every scatter plot in "Guess the correlation".
pearson = pts => {
  const mx = d3.mean(pts, d => d.x), my = d3.mean(pts, d => d.y);
  const sxy = d3.sum(pts, d => (d.x - mx) * (d.y - my));
  return sxy / Math.sqrt(d3.sum(pts, d => (d.x - mx) ** 2) * d3.sum(pts, d => (d.y - my) ** 2));
}

// cloudOf(r): 100 random points from a population in which x and y are standard normal
// and correlate at exactly r. Each point draws x and an independent error e, both standard
// normal, and sets y = r * x + sqrt(1 - r^2) * e, which keeps the variance of y at 1 and
// makes the covariance of x and y, here equal to their correlation, exactly r. The
// correlation within each sample of 100 still varies around r (with a standard deviation
// of about 0.1 when r is near 0, and less as r approaches -1 or 1), which is why the r
// printed under a cloud rarely matches the slider exactly.
cloudOf = r => {
  const g = d3.randomNormal(0, 1);
  return d3.range(100).map(() => {
    const x = g(), e = g();
    return {x, y: r * x + Math.sqrt(1 - r * r) * e};
  });
}

// scatter(pts): the square scatter plot drawn for every cloud, with both axes fixed from
// -3.5 to 3.5, so that clouds with different correlations share one scale and can be
// compared by eye.
scatter = pts => Plot.plot({
  width: Math.min(width, 420), height: 340, marginLeft: 40,
  x: {domain: [-3.5, 3.5], label: "x"}, y: {domain: [-3.5, 3.5], label: "y"},
  style: {fontSize: "12px"},
  marks: [Plot.frame({stroke: "#DDE3E8"}), Plot.dot(pts, {x: "x", y: "y", r: 3.5, fill: navy, fillOpacity: 0.8})]
})

// tableOf(head, body): an HTML table in the style of the course site (Bootstrap classes
// "table table-sm", at most 620 px wide). head is an array of column headings and body an
// array of rows, each an array of cells. The first column is left-aligned and the others
// are right-aligned, because they hold numbers. Cells are inserted as HTML, so <strong>
// works inside them; pass it only text written on this page, never text typed by a
// visitor. Used by "Column percentages", where the typed counts reach the table only as
// numbers.
tableOf = (head, body) => {
  const t = document.createElement("table");
  t.className = "table table-sm";
  t.style.maxWidth = "620px";
  // cell(v, tag, i): one <th> or <td> holding v, right-aligned unless it sits in the
  // first column (i = 0)
  const cell =(v, tag, i) => `<${tag}${i > 0 ? ' style="text-align: right;"' : ""}>${v}</${tag}>`;
  t.innerHTML = `<thead><tr>${head.map((h, i) => cell(h, "th", i)).join("")}</tr></thead>` +
    `<tbody>${body.map(r => `<tr>${r.map((v, i) => cell(v, "td", i)).join("")}</tr>`).join("")}</tbody>`;
  return t;
}

Guess the correlation

Choose a correlation and look at the kind of scatter plot that it produces: each click draws a new sample of 100 cases. Then test yourself: draw a puzzle, make a guess, and tick the box to check it. The website guessthecorrelation.com turns the same exercise into a game.

viewof rr = Inputs.range([-1, 1], {value: 0.4, step: 0.05, label: "Correlation"})
viewof again = Inputs.button("New sample")
// cloud: a fresh sample of 100 at the chosen correlation. Naming the button (again)
// inside the cell makes it run afresh on every click.
cloud = {
  again;
  return cloudOf(rr);
}
html`<div>${scatter(cloud)}<p>Correlation in this sample of 100: <strong>r = ${fmt(pearson(cloud))}</strong></p></div>`
viewof puzzle = Inputs.button("New puzzle")
viewof reveal = Inputs.toggle({label: "Show the answer", value: false})
// quiz: a puzzle cloud whose correlation is drawn at random between -1 and 1 in steps of
// 0.05, together with its sample r. Naming the button (puzzle) inside the cell draws a new
// one on every click.
quiz = {
  puzzle;
  const pts = cloudOf(Math.round((Math.random() * 2 - 1) * 20) / 20);
  return {pts, r: pearson(pts)};
}
html`<div>${scatter(quiz.pts)}<p>${reveal ? html`The correlation is <strong>r = ${fmt(quiz.r)}</strong>.` : "Guess the correlation, then tick the box."}</p></div>`

Same gap, different overlap

Two groups whose averages differ by the same amount can look very different depending on how spread out each group is. The starting values are those for trust (0 to 10) among men and women in the ESS 2023–24: a gap of 0.27 points and a standard deviation of about 2.3 within each group.

viewof gap = Inputs.range([0, 4], {value: 0.27, step: 0.01, label: "Gap between the means"})
viewof spread = Inputs.range([0.5, 4], {value: 2.3, step: 0.05, label: "Spread within groups (SD)"})
dist = d3.range(-3, 14.001, 0.05).flatMap(x => [
  {group: "Group 1", x, y: dnorm(x, 5.27, spread)},
  {group: "Group 2", x, y: dnorm(x, 5.27 + gap, spread)}])
dval = gap / spread
// overlap: the share of area that the two curves have in common. Two normal curves with
// the same spread cross halfway between their means, so the shared area is twice the tail
// of either curve beyond that point, 2 * pnorm(-dval / 2).
overlap = 2 * pnorm(-dval / 2)
Plot.plot({
  width: Math.min(width, 760), height: 300, marginLeft: 30,
  x: {domain: [-3, 14], label: "Score"},
  y: {axis: null},
  color: {domain: ["Group 1", "Group 2"], range: [blue, gold], legend: true},
  style: {fontSize: "12px"},
  marks: [
    Plot.areaY(dist, {x: "x", y: "y", fill: "group", fillOpacity: 0.25}),
    Plot.line(dist, {x: "x", y: "y", stroke: "group", strokeWidth: 2.5}),
    Plot.ruleX([5.27], {stroke: blue, strokeDasharray: "5,4"}),
    Plot.ruleX([5.27 + gap], {stroke: gold, strokeDasharray: "5,4"}),
    Plot.ruleY([0])
  ]
})
md`- **Gap in standard deviations**: ${gap.toFixed(2)} ÷ ${spread.toFixed(2)} = ${dval.toFixed(2)}
- **Overlap of the two distributions**: about ${(100 * overlap).toFixed(0)}%`

Column percentages

Type the counts of a two-by-two table. Percentages within each column (each group adds up to 100%) answer the question “are men or women more trusting?”. Row percentages answer a different question, “who are the trusting?”, and depend on how many men and women happen to be in the sample. The starting counts are the BSA 2010 trust question by sex.

viewof c11 = Inputs.number({value: 240, min: 0, step: 1, label: "Men who trust"})
viewof c21 = Inputs.number({value: 224, min: 0, step: 1, label: "Men who are careful"})
viewof c12 = Inputs.number({value: 244, min: 0, step: 1, label: "Women who trust"})
viewof c22 = Inputs.number({value: 356, min: 0, step: 1, label: "Women who are careful"})
men = c11 + c21
women = c12 + c22
colMen = 100 * c11 / men
colWomen = 100 * c12 / women
tableOf(["Column percentages", "Men", "Women"],
  [["Most people can be trusted", `${colMen.toFixed(1)}%`, `${colWomen.toFixed(1)}%`],
   ["Can't be too careful", `${(100 - colMen).toFixed(1)}%`, `${(100 - colWomen).toFixed(1)}%`],
   ["<strong>Total</strong>", `<strong>100%</strong> (${men})`, `<strong>100%</strong> (${women})`]])
tableOf(["Row percentages", "Men", "Women", "Total"],
  [["Most people can be trusted", `${(100 * c11 / (c11 + c12)).toFixed(1)}%`, `${(100 * c12 / (c11 + c12)).toFixed(1)}%`, "100%"],
   ["Can't be too careful", `${(100 * c21 / (c21 + c22)).toFixed(1)}%`, `${(100 * c22 / (c21 + c22)).toFixed(1)}%`, "100%"]])
md`**${colMen.toFixed(1)}%** of men and **${colWomen.toFixed(1)}%** of women say most people can be trusted: a gap of ${fmt(colMen - colWomen, 1)} percentage points.`
