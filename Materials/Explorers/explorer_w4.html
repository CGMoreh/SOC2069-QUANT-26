Modelling dichotomous outcomes

Interactive explorer

The three tools below accompany the lecture slides. Each one recalculates as you move its sliders.

navy = "#1F394D"
gold = "#B88C00"
blue = "#3F739B"
dkgold = "#7A5C00"
grey = "#55606B"
fmt = (v, d = 2) => v.toFixed(d).replace("-", "−")
pct = (v, d = 1) => `${(100 * v).toFixed(d)}%`
plogis = v => 1 / (1 + Math.exp(-v))

Probability, odds and log-odds

Choose a probability with the slider. The odds compare the two groups with each other, p ÷ (1 − p), and the log-odds are the natural logarithm of the odds. An even split, p = 0.5, gives odds of 1 and log-odds of 0. The starting value, 0.454, is the share of respondents in the British Social Attitudes survey 2010 who say that “most people can be trusted”.

viewof p = Inputs.range([0.01, 0.99], {value: 0.454, step: 0.001, label: "Probability"})
odds = p / (1 - p)
logodds = Math.log(odds)
ruler = (label, note, domain, value, ticks, w) => Plot.plot({
  height: 84, width: w, marginLeft: 175, marginRight: 30, marginTop: 30,
  x: {domain, ticks, label: null, tickFormat: d => fmt(d, Number.isInteger(d) ? 0 : 2)},
  y: {axis: null, domain: [0, 1]},
  style: {fontSize: "13px"},
  marks: [
    Plot.ruleY([0], {stroke: grey}),
    Plot.dot([value], {x: d => Math.max(domain[0], Math.min(domain[1], d)), y: 0, r: 8, fill: gold, stroke: "white"}),
    Plot.text([value], {x: d => Math.max(domain[0], Math.min(domain[1], d)), y: 0, dy: -18, text: d => fmt(d), fill: dkgold, fontWeight: "bold", fontSize: 15}),
    Plot.text([label], {frameAnchor: "left", dx: -170, y: 0, dy: -8, textAnchor: "start", fontWeight: "bold", fontSize: 16, fill: navy}),
    Plot.text([note], {frameAnchor: "left", dx: -170, y: 0, dy: 12, textAnchor: "start", fontSize: 12, fill: grey})
  ]
})
html`<table class="table table-sm" style="max-width: 620px;">
<thead><tr><th>Scale</th><th style="text-align: right;">Value</th><th>Calculation</th></tr></thead>
<tbody>
<tr><td>Probability</td><td style="text-align: right;">${p.toFixed(3)}</td><td>the share of all cases in category 1</td></tr>
<tr><td>Odds</td><td style="text-align: right;">${odds.toFixed(2)}</td><td>${p.toFixed(3)} ÷ ${(1 - p).toFixed(3)}</td></tr>
<tr><td>Log-odds</td><td style="text-align: right;">${fmt(logodds)}</td><td>ln(${odds.toFixed(2)})</td></tr>
</tbody></table>`
{
  const w = Math.min(width, 780);
  return html`<div>
  ${ruler("Probability", "from 0 to 1", [0, 1], p, [0, 0.25, 0.5, 0.75, 1], w)}
  ${ruler("Odds", "from 0, no upper limit", [0, 20], odds, [0, 1, 5, 10, 15, 20], w)}
  ${ruler("Log-odds", "no lower or upper limit", [-5, 5], logodds, [-4, -2, 0, 2, 4], w)}
  </div>`;
}

The logistic curve

A logistic regression is a straight line on the log-odds scale (left) and an S-curve on the probability scale (right). The intercept is the log-odds when x is 0, and the slope is the change in log-odds for each one-unit step in x. The gold step shows what a one-unit step does on each scale. The starting values are those of the car-ownership example in the slides, with x as household income in £10,000s.

  • Set the slope to 0: the curve goes flat, because the probability no longer depends on x.
  • Make the slope negative: the S runs downhill.
  • Change only the intercept: the curve slides sideways and keeps its steepness.
  • Move the step along the x axis: on the left it always rises by the slope, while on the right the change in probability is largest in the middle of the S.
viewof b0 = Inputs.range([-6, 6], {value: -2.12, step: 0.01, label: "Intercept"})
viewof b1 = Inputs.range([-2, 2], {value: 0.8, step: 0.01, label: "Slope"})
viewof x0 = Inputs.range([0, 9], {value: 2, step: 0.5, label: "Step from x ="})
grid = d3.range(0, 10.0001, 0.05).map(x => ({x, lo: b0 + b1 * x, p: plogis(b0 + b1 * x)}))
step = ({lo0: b0 + b1 * x0, lo1: b0 + b1 * (x0 + 1), p0: plogis(b0 + b1 * x0), p1: plogis(b0 + b1 * (x0 + 1))})
mid = b1 === 0 ? null : -b0 / b1
{
  const w = Math.max(200, Math.floor((Math.min(width, 800) - 44) / 2));
  const logPlot = Plot.plot({
    width: w, height: 300, marginLeft: 48, clip: true,
    x: {domain: [0, 10], label: "x"},
    y: {domain: [-10, 10], label: "Log-odds", grid: true},
    style: {fontSize: "12px"},
    marks: [
      Plot.ruleY([0], {stroke: "#9AA3AB", strokeDasharray: "4,3"}),
      Plot.line(grid, {x: "x", y: "lo", stroke: navy, strokeWidth: 3}),
      Plot.line([[x0, step.lo0], [x0 + 1, step.lo0], [x0 + 1, step.lo1]], {stroke: gold, strokeWidth: 2.5}),
      Plot.dot([[0, b0]], {x: d => d[0], y: d => d[1], r: 6, fill: navy, stroke: "white"}),
      Plot.text([[0, b0]], {x: d => d[0], y: d => d[1], dx: 10, dy: 14, textAnchor: "start", text: () => `${fmt(b0)} (intercept)`, fill: navy, fontWeight: "bold", fontSize: 13})
    ]
  });
  const probPlot = Plot.plot({
    width: w, height: 300, marginLeft: 48,
    x: {domain: [0, 10], label: "x"},
    y: {domain: [0, 1], label: "Probability", grid: true, tickFormat: "%"},
    style: {fontSize: "12px"},
    marks: [
      Plot.ruleY([0.5], {stroke: "#9AA3AB", strokeDasharray: "4,3"}),
      Plot.line(grid, {x: "x", y: "p", stroke: navy, strokeWidth: 3}),
      Plot.line([[x0, step.p0], [x0 + 1, step.p0], [x0 + 1, step.p1]], {stroke: gold, strokeWidth: 2.5}),
      Plot.dot([[0, plogis(b0)]], {x: d => d[0], y: d => d[1], r: 6, fill: blue, stroke: "white"}),
      Plot.text([[0, plogis(b0)]], {x: d => d[0], y: d => d[1], dx: 10, dy: plogis(b0) > 0.85 ? 14 : -12, textAnchor: "start", text: () => pct(plogis(b0)), fill: blue, fontWeight: "bold", fontSize: 13})
    ]
  });
  return html`<div style="display: flex; flex-wrap: wrap; gap: 20px;">${logPlot}${probPlot}</div>`;
}
md`- **Odds ratio** for a one-unit step: e<sup>${fmt(b1)}</sup> = ${Math.exp(b1).toFixed(2)}
- **Probability at x = 0**: the intercept converted, ${pct(plogis(b0))}
- **Where the curve crosses 50%**: ${mid === null ? "nowhere, because a slope of 0 gives a flat line" : (mid >= 0 && mid <= 10 ? `x = ${fmt(mid)}` : `x = ${fmt(mid)}, outside the plotted range`)}
- **The gold step**, from x = ${x0} to x = ${x0 + 1}: the log-odds change by ${fmt(b1)}, the odds are multiplied by ${Math.exp(b1).toFixed(2)}, and the probability moves from ${pct(step.p0)} to ${pct(step.p1)}, a change of ${fmt(100 * (step.p1 - step.p0), 1)} percentage points`

The BSA 2010 model

The model from the lecture and from Exercise 4.1.1 of the workshop: social trust (1 = “most people can be trusted”, 0 = “can’t be too careful”) regressed on age and sex in the British Social Attitudes survey 2010 (n = 1,060). Choose an age and a sex to follow the calculation from the coefficients in JASP’s Coefficients table to a predicted probability.

viewof age = Inputs.range([18, 95], {value: 40, step: 1, label: "Age"})
viewof sex = Inputs.radio(["Man", "Woman"], {value: "Woman", label: "Sex"})
bsa = ({b0: -0.25716, age: 0.0062312, female: -0.43708})
lo_bsa = bsa.b0 + bsa.age * age + (sex === "Woman" ? bsa.female : 0)
odds_bsa = Math.exp(lo_bsa)
p_bsa = plogis(lo_bsa)
bsa_curves = ["Man", "Woman"].flatMap(s => d3.range(0, 98).map(a => ({
  sex: s, age: a, p: plogis(bsa.b0 + bsa.age * a + (s === "Woman" ? bsa.female : 0))
})))
html`<table class="table table-sm" style="max-width: 620px;">
<thead><tr><th>Step</th><th>Calculation</th><th style="text-align: right;">Result</th></tr></thead>
<tbody>
<tr><td>Log-odds</td><td>${fmt(bsa.b0, 3)} + 0.00623 × ${age}${sex === "Woman" ? " − 0.437" : ""}</td><td style="text-align: right;">${fmt(lo_bsa, 3)}</td></tr>
<tr><td>Odds</td><td>e<sup>${fmt(lo_bsa, 3)}</sup></td><td style="text-align: right;">${odds_bsa.toFixed(3)}</td></tr>
<tr><td>Probability</td><td>${odds_bsa.toFixed(3)} ÷ (1 + ${odds_bsa.toFixed(3)})</td><td style="text-align: right;"><strong>${pct(p_bsa)}</strong></td></tr>
</tbody></table>`
Plot.plot({
  width: Math.min(width, 780), height: 320, marginLeft: 50,
  x: {domain: [0, 100], label: "Age"},
  y: {domain: [0, 1], label: "Predicted probability of trusting", grid: true, tickFormat: "%"},
  color: {domain: ["Man", "Woman"], range: [navy, gold], legend: true},
  style: {fontSize: "12px"},
  marks: [
    Plot.line(bsa_curves.filter(d => d.age >= 17), {x: "age", y: "p", stroke: "sex", strokeWidth: 3}),
    Plot.line(bsa_curves.filter(d => d.age <= 17), {x: "age", y: "p", stroke: "sex", strokeWidth: 2, strokeDasharray: "6,4"}),
    Plot.dot([{age, p: p_bsa, sex}], {x: "age", y: "p", r: 8, fill: "sex", stroke: "white", strokeWidth: 2}),
    Plot.text([{age, p: p_bsa, sex}], {x: "age", y: "p", dy: -16, text: d => pct(d.p), fill: dkgold, fontWeight: "bold", fontSize: 13})
  ]
})

The dashed lines below age 17 extend the model beyond the data. They end at age 0, where the predicted probability for men is the intercept converted (−0.257 gives 43.6%), and for women the intercept plus the sex coefficient (−0.257 − 0.437 = −0.694 gives 33.3%).
