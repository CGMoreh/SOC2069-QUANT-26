Measurement and Description

Interactive explorer

The tools below let you change the numbers behind this week’s measures and watch how each measure responds. They recalculate as you move the sliders.

navy = "#1F394D"
gold = "#B88C00"
blue = "#3F739B"
dkgold = "#7A5C00"
light = "#CCDDEA"
fmt = (v, d = 2) => v.toFixed(d).replace("-", "−")
dnorm = (x, m, s) => Math.exp(-0.5 * ((x - m) / s) ** 2) / (s * Math.sqrt(2 * Math.PI))
tableOf = (head, body) => {
  const t = document.createElement("table");
  t.className = "table table-sm";
  t.style.maxWidth = "620px";
  const cell = (v, tag, i) => `<${tag}${i > 0 ? ' style="text-align: right;"' : ""}>${v}</${tag}>`;
  t.innerHTML = `<thead><tr>${head.map((h, i) => cell(h, "th", i)).join("")}</tr></thead>` +
    `<tbody>${body.map(r => `<tr>${r.map((v, i) => cell(v, "td", i)).join("")}</tr>`).join("")}</tbody>`;
  return t;
}
ess = [{"v": 0, "pct": 3.5}, {"v": 1, "pct": 3.5}, {"v": 2, "pct": 6.1}, {"v": 3, "pct": 8.7}, {"v": 4, "pct": 7.0}, {"v": 5, "pct": 19.6}, {"v": 6, "pct": 13.8}, {"v": 7, "pct": 20.2}, {"v": 8, "pct": 13.0}, {"v": 9, "pct": 2.9}, {"v": 10, "pct": 1.8}]

One very rich household

Nine households, with incomes in thousands of pounds. Move the income of the richest household: the mean (gold line) follows it, while the median (the blue bar in the middle) does not move at all.

viewof top = Inputs.range([45, 1000], {value: 400, step: 5, label: "Richest household (£000s)"})
inc = [18, 22, 25, 28, 31, 34, 38, 45, top].sort((x, y) => x - y).map((v, i) => ({household: i + 1, income: v}))
incMean = d3.mean(inc, d => d.income)
incMedian = d3.median(inc, d => d.income)
Plot.plot({
  width: Math.min(width, 760), height: 320, marginLeft: 50,
  x: {label: "Household, from poorest to richest", padding: 0.15},
  y: {domain: [0, Math.max(120, top * 1.05)], label: "Income (£000s)", grid: true},
  style: {fontSize: "12px"},
  marks: [
    Plot.barY(inc, {x: "household", y: "income", fill: d => d.household === 5 ? blue : "#9AA3AB"}),
    Plot.ruleY([incMean], {stroke: gold, strokeWidth: 2.5, strokeDasharray: "6,4"}),
    Plot.text([incMean], {y: d => d, frameAnchor: "left", dx: 6, dy: -8, textAnchor: "start", text: d => `mean = ${d.toFixed(0)}`, fill: dkgold, fontWeight: "bold"}),
    Plot.ruleY([0])
  ]
})
md`- **Mean**: ${incMean.toFixed(1)} thousand pounds, pulled up by one household
- **Median**: ${incMedian} thousand pounds, the income of the fifth household of nine`

The standard deviation by hand

Five people answer the trust question on a scale from 0 to 10. Change their answers and follow each step: subtract the mean, square the deviations, add them up, divide by the number of people minus one (the variance), and take the square root (the standard deviation).

viewof sA = Inputs.range([0, 10], {value: 2, step: 1, label: "Person A"})
viewof sB = Inputs.range([0, 10], {value: 4, step: 1, label: "Person B"})
viewof sC = Inputs.range([0, 10], {value: 5, step: 1, label: "Person C"})
viewof sD = Inputs.range([0, 10], {value: 7, step: 1, label: "Person D"})
viewof sE = Inputs.range([0, 10], {value: 7, step: 1, label: "Person E"})
scores = [["A", sA], ["B", sB], ["C", sC], ["D", sD], ["E", sE]].map(([p, x]) => ({p, x}))
mean5 = d3.mean(scores, d => d.x)
sq = d3.sum(scores, d => (d.x - mean5) ** 2)
var5 = sq / (scores.length - 1)
sd5 = Math.sqrt(var5)
tableOf(["Person", "Trust (x)", "x − mean", "(x − mean)²"],
  [...scores.map(d => [d.p, d.x, fmt(d.x - mean5, 1), ((d.x - mean5) ** 2).toFixed(2)]),
   ["<strong>Sum</strong>", d3.sum(scores, d => d.x), "0", `<strong>${sq.toFixed(2)}</strong>`]])
md`Mean = ${d3.sum(scores, d => d.x)} ÷ 5 = **${mean5.toFixed(1)}**; variance = ${sq.toFixed(2)} ÷ 4 = **${var5.toFixed(2)}**; standard deviation = √${var5.toFixed(2)} = **${sd5.toFixed(2)}**: a typical answer lies about ${sd5.toFixed(1)} points from the mean.`
Plot.plot({
  width: Math.min(width, 760), height: 150, marginLeft: 30,
  x: {domain: [0, 10], label: "Trust (0 to 10)", ticks: d3.range(0, 11)},
  y: {axis: null, domain: [0, 1]},
  style: {fontSize: "12px"},
  marks: [
    Plot.rect([{x1: Math.max(0, mean5 - sd5), x2: Math.min(10, mean5 + sd5)}], {x1: "x1", x2: "x2", y1: 0.15, y2: 0.85, fill: light}),
    Plot.ruleX([mean5], {stroke: gold, strokeWidth: 3}),
    Plot.dot(scores, Plot.dodgeY({x: "x", r: 9, fill: navy, anchor: "middle"})),
    Plot.text(scores, Plot.dodgeY({x: "x", r: 9, text: "p", fill: "white", fontWeight: "bold", anchor: "middle"}))
  ]
})

Same average, different spread

Two towns have the same mean household income, £30,000. Change the standard deviation of each: about two-thirds of households in a roughly bell-shaped distribution lie within one standard deviation of the mean.

viewof sdA = Inputs.range([1, 20], {value: 5, step: 0.5, label: "Town A spread (SD, £000s)"})
viewof sdB = Inputs.range([1, 20], {value: 15, step: 0.5, label: "Town B spread (SD, £000s)"})
towns = d3.range(0, 80.01, 0.5).flatMap(x => [{town: "Town A", x, y: dnorm(x, 30, sdA)}, {town: "Town B", x, y: dnorm(x, 30, sdB)}])
Plot.plot({
  width: Math.min(width, 760), height: 300, marginLeft: 50,
  x: {domain: [0, 80], label: "Household income (£000s)"},
  y: {axis: null},
  color: {domain: ["Town A", "Town B"], range: [blue, gold], legend: true},
  style: {fontSize: "12px"},
  marks: [
    Plot.areaY(towns, {x: "x", y: "y", fill: "town", fillOpacity: 0.25}),
    Plot.line(towns, {x: "x", y: "y", stroke: "town", strokeWidth: 2.5}),
    Plot.ruleX([30], {stroke: navy, strokeDasharray: "5,4"}),
    Plot.ruleY([0])
  ]
})
md`- **Town A**: about two-thirds of households earn between £${30 - sdA}k and £${30 + sdA}k
- **Town B**: about two-thirds earn between £${Math.max(0, 30 - sdB)}k and £${30 + sdB}k`

Trust in the ESS 2023–24

The distribution of the 1,680 valid answers to the trust question in the UK sample of the European Social Survey 2023–24 (the data used in Worksheet 1), with its three measures of the centre. The mean sits below the median because the low answers on the left are spread further from the middle than the high answers on the right.

Plot.plot({
  width: Math.min(width, 760), height: 300, marginLeft: 50,
  x: {domain: [-0.6, 10.6], label: "Trust: 0 = you can't be too careful, 10 = most people can be trusted", ticks: d3.range(0, 11)},
  y: {domain: [0, 26], label: "% of valid answers", grid: true},
  style: {fontSize: "12px"},
  marks: [
    Plot.rectY(ess, {x1: d => d.v - 0.4, x2: d => d.v + 0.4, y: "pct", fill: d => d.v === 7 ? navy : light, title: d => `${d.v}: ${d.pct}%`}),
    Plot.ruleX([5.40], {stroke: gold, strokeWidth: 3}),
    Plot.ruleX([6], {stroke: blue, strokeWidth: 2.5, strokeDasharray: "6,4"}),
    Plot.text(["mean 5.40"], {x: 5.40, frameAnchor: "top", dy: 6, dx: -6, textAnchor: "end", fill: dkgold, fontWeight: "bold"}),
    Plot.text(["median 6"], {x: 6, frameAnchor: "top", dy: 6, dx: 6, textAnchor: "start", fill: blue, fontWeight: "bold"}),
    Plot.text(["mode 7"], {x: 7, y: 20.2, dy: -10, fill: navy, fontWeight: "bold"}),
    Plot.ruleY([0])
  ]
})
