JASP Quick Reference

Everything you need from JASP for the five workshops and the assignment, on one page. Menu names follow the worksheets; small details may differ slightly between JASP versions.

Which analysis for which variables?

Start by deciding the measurement type of each variable (Nominal, Ordinal or Scale), then pick the tool:

What you want to describe or model Variables JASP tool Workshop
One variable Categorical Descriptives > Descriptive Statistics, Frequency tables 1
One variable Scale Descriptive Statistics: mean, median, SD; Distribution plots 1
Two variables Categorical × categorical Frequencies > Contingency Tables (column %) 2
Two variables Scale × categorical Descriptive Statistics, Scale variable in Variables, categorical in Split; Boxplots 2
Two variables Scale × Scale Customizable plots > Scatter plots; Regression > Correlation 2-3
An outcome explained by one or more predictors Scale outcome Regression > Linear Regression 3
An outcome explained by one or more predictors Two-category outcome Regression > Logistic Regression 4
How sure we can be about a model’s estimates Any regression Statistics > Confidence intervals; read the SE, 95% CI and p columns 5

Opening, saving and getting around

Task How
Open a dataset (.sav, .csv) ☰ (hamburger) > Open > Computer > Browse. Don’t double-click .sav files: they open in SPSS.
Switch between analyses and data Analyses tab / Edit Data tab (the data view is where accidental changes happen: be careful)
Save data, analyses and notes together ☰ > Save as > Computer > Browse, as a .jasp file
Add your interpretation to an output Hover over the output title > small down-arrow > Add Note
Copy an output into Word Hover over the output title > down-arrow > Copy, then paste (tables usually need tidying in Word)
Make a plot bigger Drag its bottom-right corner
Select all variables in a list Click one, then Ctrl + A

Variable types

Task How
Change a variable’s type for one analysis Click the type icon next to the variable once it is in an analysis box. A small star marks a forced type.
Change a variable’s type permanently Edit Data > click the column header > change the type in the Label editor
Treat a 0/1 variable as numeric Put it in Covariates (as Scale) rather than Factors: same coefficient, and JASP can standardise it

Cleaning and recoding in the Label editor

Open it with Edit Data, then double-click a column header.

Task How
Rename a variable Edit the Name field
Fix or shorten value labels Click into the Label cell and type
Set “Don’t know”, “Refusal” etc. as missing Missing values tab > add the value (e.g. 8, 9). The values disappear from all analyses.
Exclude rows for now (subset the data) Untick the value in the Filter column. Rows turn grey and are excluded from every analysis until you tick them again.
Recode values (e.g. 2 → 0) Click into the Value cell and type the new value
Collapse categories (e.g. 1-3 → 0, 4-5 → 1) Give several categories the same value (see the recoding videos in Worksheet 4)
Change which category comes first Turn off Automatically order labels by their value, then move labels with the up/down arrows
Reverse the order of all labels Turn off automatic ordering, then press the reverse order button (parallel arrows)
Standardise a variable (z-scores) Create a computed column with the zScores() drag-and-drop function (Worksheet 3)
WarningCheck the codes before you analyse

Survey files often store non-answers (“Don’t know” = 8, “Refusal” = 9, “Can’t choose” = 12) as ordinary values that JASP treats as valid. And 0-10 scales are sometimes stored as the values 1 to 11. Always run a frequency table first and compare the values with their labels.

Descriptive statistics (Workshops 1-2)

Task Where in Descriptives > Descriptive Statistics
Frequency table Tables > Frequency tables; raise Maximum distinct values for long scales (e.g. 0-10 has 11 values)
Mean, median, mode, SD, range Statistics (tick what you need)
Many variables in one readable table Transpose descriptives table
Histogram / distribution Basic plots > Distribution plots
Compare groups Put the grouping variable in Split
Box plots, scatter plots Customizable plots; in a scatter plot the first variable listed goes on the x-axis

Contingency tables (Frequencies > Contingency Tables): put the outcome in Rows and the predictor in Columns, then under Cells untick Observed and tick Column percentages, so each column adds to 100%. Untick χ² under Statistics if you don’t need it.

TipTwo habits that save marks
  1. Fit your models as nested models in one analysis (M₀, M₁, M₂ …): JASP then uses the same respondents in every model, so the models are comparable.
  2. Write your interpretation in a JASP note right under each output as you go, then copy it into your report.

The analysis cycle for your assignment

  1. Identify your variables and summarise them.
  2. Describe the outcome and main predictor in detail (frequency tables, distribution plots).
  3. Clean and transform (missing values, recodes, labels, reference categories).
  4. Look at bivariate relationships (contingency tables, box plots, scatter plots). ↺ back to 3 if needed.
  5. Fit a simple (one-predictor) regression. ↺ back to 3 if needed.
  6. Fit a multiple regression with your control variables. ↺ back to 3 if needed.
  7. Interpret: direction and size of each association, model fit, and precision (CIs and p-values).
  8. Identify limitations (measurement, sample, design) and how they could be addressed.
  9. Discuss what the results mean sociologically for your research question.

See the Interpretation Guide for model sentences for each kind of output.
